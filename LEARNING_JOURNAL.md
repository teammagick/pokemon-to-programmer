# Learning Journal and Review Tracker

Use this file as a **template**. To record personal progress without modifying the shared curriculum, copy it to `my-learning-journal.md` or keep a personal copy in your notes. Checkpoints should be solved using Python, not just marked completed.

## How to know whether you have learned something

- **Encountered:** I have read and run a worked example.
- **Understood:** I can predict its output and explain why it behaves that way.
- **Applied:** I can modify an example and solve a related problem.
- **Independent:** I can solve an unfamiliar task without copying.
- **Retained:** I can do this again after a delay without rereading.

**Mastery rule:** A topic is provisionally learned when you can explain it and solve a new problem on your own. Mark it retained only after a later successful attempt. These labels are reflection aids, not a validated assessment instrument.

## Spaced retrieval schedule

For every new topic, try a short closed-notebook recall test:

| When | What to do | Record |
| --- | --- | --- |
| Same day | Answer one prediction and one independent MAKE task | What went wrong or surprised you |
| Next day | Rebuild a solution from memory | Correct without notes? |
| 3 days later | Solve a different task using the same concept | New task and result |
| 7 days later | Mix this topic with another one | Whether you recognized when to use it |
| Later as needed | Revisit any topic that failed | Next review date |

These intervals are a **suggested starting schedule**, not a fixed scientific optimum. Move reviews sooner if you forget and farther apart as recall becomes reliable.
